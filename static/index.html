Forget or delete a source

          
These are two different operations and are shown as two different controls. Forget stops an entry being recalled or returned and keeps its content and revision trail, so it can be restored. Delete source removes the stored content; only the audited fact that the entry existed remains, and it cannot be undone.

          
Select a search result to see its privacy controls.

          


          
Export review

          
An export is three separate acts: assemble a draft, review the exact contents for a named audience, then release. Nothing leaves on the first two. The draft below is what would leave.

            Available features and advanced operations
            
Available now

            
Chat and durable activity, approval prompts, reviewed memory suggestions, sanitized history and exports, transcript imports, project settings, and custom provider management are available in the navigation. Provider API keys are write-only: the UI can replace one but never read it back.

            
Not yet available in the UI

            
Some advanced diagnostics, governance, recovery, and exact-original archive operations remain API-only. Provider/model controls and the allowlisted server folder chooser are available below.

            
Advanced API-only operations

            
Some diagnostics, governance, recovery, and exact-original archive operations have authenticated APIs but no complete browser controls yet. The activity panel shows recorded work, not the model's private reasoning. Unavailable external conversation text cannot be recovered from tool records.
