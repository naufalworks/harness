Forget or delete a source

          
These are two different operations and are shown as two different controls. Forget stops an entry being recalled or returned and keeps its content and revision trail, so it can be restored. Delete source removes the stored content; only the audited fact that the entry existed remains, and it cannot be undone.

          
Select a search result to see its privacy controls.

Project & models

          
The main model answers. The extraction model proposes memories. The verification model checks file and symbol claims against recorded tool evidence. Recall combines local FTS5 and deterministic offline vectors—no network or extra recall model call.

          

            What the UI can do today · P21 feature status
            
Available now

            
Chat and durable activity, approval prompts, reviewed memory suggestions, sanitized history and exports, transcript imports, and project settings are available in the navigation. You can type a server project path and type model IDs; Show provider model names lists IDs from the one configured provider.

            
Not yet available in the UI

            
Adding or editing a custom provider and its API key, selecting models from a dropdown, and browsing folders on the Harness server are planned P21 work. Editing the model names below does not change the provider connection.

            
Advanced API-only operations

            
Some diagnostics, governance, recovery, and exact-original archive operations have authenticated APIs but no complete browser controls yet. The activity panel shows recorded work, not the model's private reasoning. Unavailable external conversation text cannot be recovered from tool records.
